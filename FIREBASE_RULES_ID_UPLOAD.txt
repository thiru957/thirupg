CODEKASA — ID PHOTO UPLOAD (no Firebase Storage needed)
=======================================================
The guest's ID photo is now shrunk to ~200 KB and saved inside the admin-only
'bookingIds' record in Firestore. Nothing is sent to Firebase Storage.

FIRESTORE rules to check (Firestore -> Rules):
- 'bookingIds' : guests may CREATE, only the admin may read/update/delete.
  If your rule lists allowed fields (hasOnly), add 'idImage' inside persons - or, simplest, do not list persons' inner fields.
- 'bookings'   : create must allow the new field 'tenant' (father/spouse name, age, address) for monthly stays.
  If your rules list allowed fields with hasOnly([...]), add 'tenant'.
